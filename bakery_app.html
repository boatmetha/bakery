ตัวอย่างข้อมูลที่จะ import:
☁️ ตั้งค่า Google Drive Sync
ข้อมูลทั้งหมดจะถูกบันทึกใน Google Drive เป็นไฟล์ bakery_data.json ทุกคนที่มี File ID จะอ่าน/เขียนไฟล์เดียวกัน
Google Client ID (ทุกคนต้องใส่)
console.cloud.google.com → New Project → APIs & Services → Enable Google Drive API → Credentials → Create OAuth 2.0 Client ID (Web app) → Authorized JS origins: URL ของ GitHub Pages คุณ
Shared File ID (เว้นว่างถ้าคุณเป็นคนสร้างไฟล์ครั้งแรก)
ถ้าคุณเป็น Owner — เว้นว่างไว้ ระบบจะสร้างไฟล์ให้อัตโนมัติ แล้วให้ File ID มา
ถ้าคุณเป็น User อื่น — ใส่ File ID ที่ Owner แชร์มาให้
✅ สร้างไฟล์แล้ว — แชร์ File ID นี้ให้ User อื่น
1. ไปที่ Google Drive → คลิกขวาที่ bakery_data.json → Share → เพิ่ม Email ของ User อื่น (Editor)
2. ส่ง File ID ด้านล่างให้ User อื่นใส่ในช่อง "Shared File ID"
